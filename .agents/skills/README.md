# The Last Draw project skills

Eleven repository-native skills. Each SKILL.md has a name and trigger description, required live references, executable workflow, output contract and acceptance boundaries. Load skills by task via registry.json; AGENTS.md is the entry point. These files are intended for compatible agents and manual connector retrieval by ChatGPT; presence in GitHub does not install a ChatGPT plugin or guarantee automatic discovery in every client.

| Skill | Responsibility |
|---|---|
| [tld-production](tld-production/SKILL.md) | Orchestrate The Last Draw chapter production, revisions and approved-chapter close-out directly in ChatGPT and GitHub. Use for write the next chapter, continue the novel, revise a chapter, or resume production. |
| [tld-repository](tld-repository/SKILL.md) | Read, audit, safely update and verify the canonical The Last Draw GitHub repository, including recursive inventory, concurrent commits and public/private boundaries. Use for Git tasks, research integration, status queries or chapter preflight. |
| [tld-source-distillation](tld-source-distillation/SKILL.md) | Ingest and deeply distill books, guides, rules references and supplied research for The Last Draw using NDM 1.0; perform lexical and semantic analysis, evidence mapping and original strategic/narrative abstractions. Use for absorb, distill, study or integrate sources into Git. |
| [tld-continuity](tld-continuity/SKILL.md) | Retrieve and verify the authoritative private manuscript archive, track timeline, character knowledge, money, objects, relationships and obligations, and check provisional narrative changes before writing or approving The Last Draw. |
| [tld-chapter-planning](tld-chapter-planning/SKILL.md) | Plan an original The Last Draw chapter or optional interlude using live canon, pilot goals, causal scene design, character agency and commercial serial pacing. Use for chapter briefs, outline, beats or planning the next chapter. |
| [tld-competitive-evidence](tld-competitive-evidence/SKILL.md) | Autonomously research and verify Riftbound mechanics, card identities, deck choices, matchup hypotheses, resources, scoring, prices and fictional competition scenes in The Last Draw. Use before technical prose or for game evidence audits. |
| [tld-prose](tld-prose/SKILL.md) | Write original idiomatic American English sports-fiction chapters and character interludes for The Last Draw, using project voice, functional narrative grammar, realistic community dialogue and verified competitive decisions. |
| [tld-editorial-review](tld-editorial-review/SKILL.md) | Perform developmental, structural, psychological, technical, line and natural-prose review of exact-version The Last Draw chapter candidates; execute metrics, revision diffs and evidence checks without fake quality scores. |
| [tld-originality](tld-originality/SKILL.md) | Apply NDM 2.0 originality screening to The Last Draw drafts against every approved chapter and supplement, lexical fingerprints, retired expressions and semantic usage signatures. Use before acceptance, revisions or recursive distillation. |
| [tld-closeout](tld-closeout/SKILL.md) | Close an explicitly author-approved The Last Draw chapter or supplement, lock exact bytes, recursively distill, retire expressions, merge continuity, verify the private archive and update public-safe Git status. Use only after explicit approval or to repair an incomplete approved close-out. |
| [tld-publication](tld-publication/SKILL.md) | Assess The Last Draw commercial readiness, Webnovel contract preparation, reader research, packaging, release cadence and rights. Use for income, monetization, market validation, synopsis or publishing requests. |

Main chapter route: repository → verified archive/continuity → chapter brief → scoped competition evidence (when needed) → original prose → editorial review → originality → deliver for explicit approval. Only then close-out, private archive verification, public-safe Git status. Research ingestion and commercial preparation have separate routes. Skill files never override canonical documents, authorize publication or advance chapter state. No forced use of every resource on every scene.

Run `python .agents/skills/validate_skills.py` from the repository root for structural verification. This validates files, references, routing and approval separation; it is not a chapter, game-engine or archive test.
