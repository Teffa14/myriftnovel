## Build the private brief
Run tld-repository and tld-continuity before planning a draft. Confirm next pending unit and any outstanding approval/close-out. Follow existing arc and pilot, retaining intentional unresolved questions. A supplement is not a main-chapter substitution; use the interlude protocol only when requested or planned.
Choose one POV per scene, concrete objective, place/date/time, independent opposing goal, stakes, initial state, knowledge constraints, options, choice, consequence, state delta, and link to longer arc. Identify meaningful changes even for quiet scenes; ensure each beat follows causally. Select research mechanism IDs by function and compare execution against private usage signatures. Do not recycle prior chapter architecture or use examples as text templates.
Build the early reader promise through a real disturbance and recognizable stakes; establish skill through observable action, not asserted genius. Use credible escalation, independent rival competence and actual constraints (time, access, finances, relationships). Choose an earned closure or unresolved question rather than obligatory cliffhangers. No forced romance, supernatural cheat, repetitive humiliation or automatic admiration.
If technical decisions matter, route to tld-competitive-evidence before locking the scene. Establish what must be proved, what can remain generic and what is a character's hypothesis. If evidence fails, revise the specific scene rather than inventing results.

Typical main-chapter length 1,700–2,200 words, not a quota. Brief does not authorize canon or publication.

Before finalizing any brief, load active author directives and linked private records, record per-directive alignment and preserve unresolved implementation choices. Missing required private records block a claim of verified alignment.
