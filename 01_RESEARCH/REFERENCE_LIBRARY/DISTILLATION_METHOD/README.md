# Narrative Distillation Method (NDM) v1.0
2026-11-25. Protocolo operativo portable, formalizado retrospectivamente a partir de las pasadas cuantitativas de TKA y las fichas cualitativas MSC-EX01–EX15. No es una transcripción de razonamiento privado ni un algoritmo semántico determinista. El procedimiento editorial es reproducible, pero dos analistas pueden producir abstracciones diferentes. Los controles nuevos de evidencia, deduplicación, esquema y aceptación son mejoras explícitas; no afirmar que se aplicaron retrospectivamente a todas las fichas anteriores.
 
## Inicio desde cualquier chat
Copiar íntegramente [MASTER_PROMPT.md](MASTER_PROMPT.md), adjuntar una obra o fragmento de acceso autorizado, indicar proyecto destino o dejarlo genérico. No necesita acceso a este repositorio para funcionar si se adjuntan también [METHOD.md](METHOD.md) y [OUTPUT_TEMPLATES.md](OUTPUT_TEMPLATES.md). Para ejecutar con GitHub, conectar el repositorio y revisar índice/estado antes de escribir. El prompt por sí solo define el flujo mínimo; los otros dos archivos fijan criterios de ejecución más precisos.
 
## Referencias
- [METHOD.md](METHOD.md): procedimiento, pasos, niveles y aceptación.
- [MASTER_PROMPT.md](MASTER_PROMPT.md): instrucciones autocontenidas para cualquier chat.

- ../../../02_STYLE_BIBLE/NARRATIVE_GRAMMAR/GENERATION_PROTOCOL.md: uso posterior, separado del análisis.
 
No guardar prosa íntegra protegida en repositorios públicos. No usar este método para reconstruir una obra ni copiar su expresión distintiva. Transferir funciones generales a una voz original.
