## Strategic contribution
Set 1 evaluates repeated protection as an attrition engine: maintain sufficient buffs and usable resources, choose which bodies matter and convert surviving threats into score. Defense is an allocation problem across locations, not a single Might total. Compare high-value concentrated protection against displacement and a second scoring route. Historical Aurora matchup reverses the role toward earlier pressure. Set 2 explicitly shifts chosen champion and toward mobile scoring as bounce and faster pacing weaken the old hold plan. Set 3 begins to favor cross-archetype answers over narrowly targeting one Legend as the pool expands. No completed Set 3 configuration is supplied.
