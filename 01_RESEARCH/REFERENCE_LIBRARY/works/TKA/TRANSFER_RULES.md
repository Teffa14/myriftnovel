## Aplicación
Escena competitiva: objetivo → estado legal y restricciones → hipótesis → decisión → respuesta → cambio de estado → consecuencias. Motor autoridad, no alterar resultados. Escena interpersonal: deseo → fricción → gesto/dialogo con subtexto → elección → vínculo modificado. Arco: promesa → objetivo → preparación → contrajuego → revés → decisión costosa → clímax → consecuencias. Capítulo: abrir sobre conflicto relevante, cambiar estado, cerrar con consecuencia, decisión, pregunta concreta o resonancia. Rango experimental 1500–2100 palabras. No calcar trama, voz, nombres ni expresiones. Auditar causalidad, legalidad, conocimiento, motivación, claridad para novatos, economía de exposición, variedad y continuidad; lectores humanos validan.
