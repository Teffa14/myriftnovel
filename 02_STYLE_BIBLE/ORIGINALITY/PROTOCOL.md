# NDM 2.0 — Recursive manuscript distillation and originality memory
Author mandate 2026-11-25. Production extension to NDM v1.0; the source-study method and existing corpus are preserved. Every approved chapter must become a private research unit and its concrete textual realizations become retired resources. This is a blocking production gate, not an optional suggestion.

## Separate knowledge from reusable expression
Maintain three layers: (1) abstract functional grammar, reusable when appropriate; (2) usage memory, where chapter-specific choices, combinations and frequencies are tracked; (3) retired expression registry, which cannot be mined for new prose. Never paste previous sentences or use them as templates. All distinctive previously used metaphors, analogies, descriptions, lines, jokes, rhetorical formulations, opening/closing beats and extended dialogue are retired from generation; do not evade by synonym swaps, punctuation changes, altered names or sentence reorder. Common language, proper names, card names and necessary official terminology are exempt, as are deliberate narrative motifs or callbacks with documented function and justification. Exceptions are local, never blanket whitelists. Preserve character voice, canon, and readability; do not replace ordinary verbs with unnatural synonyms. Abstract mechanisms can recur with distinct events, goals, stakes, perspective and wording.

## Cycle
Before writing: enumerate repository, load canon, chapter brief, research and complete private approved archive index; require consecutive approved chapters and matching hashes. Retrieve relevant mechanism IDs and usage summaries, NOT retired prose as generation examples. For missing archive or failed hash verification, mark originality review blocked. Chapter 1 uses baseline corpus and empty private archive; zero prior chapters is valid only for the initial chapter.
Draft fresh expression; choose a different scene execution whenever prior signature would duplicate function + conflict + order of beats + payoff. After draft, run repetition_check.py against every approved chapter, plus an editorial semantic audit of all candidate scenes against the full usage index. Compare in particular the most recent five chapters for dense recurring devices; five is a provisional review window, not a hard ban. Review every flag with context and exact locator; repair material repetition and repeat both checks. Inspect internal repetitions, common phrases and near-paraphrases, dialogue cadence and attribution, gestures, thoughts, comparisons, descriptions, humor, tension, openings, closings, pacing, scene sequences and recurring plot solutions. The checker is a lexical proxy only; no numeric threshold replaces an editor. Manually compare short distinctive lines and paraphrases even without lexical flags.
After explicit editorial approval of the revised chapter: lock SHA-256 of final text; run NDM v1.0/2.0 on that exact version. Extract linguistic metrics (word forms, verbs/POS if available, connectors, sentence starts, lengths, dialogue and paragraphs), semantic beats, character voices, stylistic devices, new abstract variants, scene signatures and exact distinctive expressions to retire. Tag existing abstract IDs instead of duplicating; new candidate IDs only when distinct. Record evidence and scope. Store full chapter and all detailed usage/retirement data in private workspace only. Update canon after acceptance, then verify archive manifest/hash and originality index. No next chapter until this close-out passes. If approved text changes, create a new revision, rebuild archive index from authoritative versions, retain historical retirement of distinctive text to prevent accidental reuse, and audit downstream dependencies. Never silently rewrite accepted text to fit detector.
 
## Private storage contract
Set PRIVATE_ROOT outside the public Git checkout (or approved private repository). Folder approved/CH0001/chapter_final.md and siblings; keep original version bytes and explicit approval record. Private files: chapter_distillation.json (schema below), retired_expressions.jsonl, usage_ledger.jsonl, corpus_manifest.json, repetition_report.json, semantic_review.md, exception_ledger.jsonl. Keep archived chapters in approved only after explicit approval. Before generation verify all approved chapter numbers, exact paths and SHA-256 against manifest; never treat missing chapters as empty history. Public Git may contain only procedures, code, aggregate non-spoiler counts, abstract non-spoiler mechanisms, and synthetic examples; no hashes or exact phrase registry required publicly. 
The private chapter distillation contains chapter_id, revision, sha256, approval_ref, language, quantitative_method, metrics_executed, metrics, source_locators, beats, scenes, patterns[{id,variant_of,function,conditions,effect_hypothesis,execution_signature,locator}], retired[{id,type,locator,text,normalized_fingerprint,reason}], voice_changes, originality_review, continuity_delta_ref. Execution signature: POV + goal + obstacle + device + ordered beats + outcome + affect; store semantic summary, not prose. Usage ledger: chapter_id, scene_id, pattern_id, function, execution_signature, locator, density context, review_state. Exception ledger: chapter_id, prior_locator, new_locator, phrase/type, reason, narrative purpose, approved_by, scope. Manifest tracks chapter numbers, revisions, approval refs, file paths, hashes, distillation and registration status. Distinctive text is private and used for comparison only. 
## Screening defaults and acceptance
Run: python 02_STYLE_BIBLE/ORIGINALITY/repetition_check.py /private/draft.md /private/approved > /private/repetition_report.json
Defaults: normalized exact 8-word n-gram overlap (cross-chapter), paragraph token trigram Jaccard >=0.45 for paragraphs of at least 20 words, internal repeated 5-grams >=3 occurrences. These are configurable only by explicit code revision; experimental thresholds chosen for recall, not empirically calibrated. Exact overlaps require review even when technical terminology; do not blanket-ban common wording. No flags does not prove originality. Script intentionally produces fingerprints and indices rather than quote text. It does not check archive manifest, detect all short jokes, perform semantic comparisons, generate distillation or approve chapters; those remain required editorial steps. 
G6 originality and recursive close-out: all approved prior chapter files enumerated and hashes verified; lexical screening actually executed; semantic and short-phrase audit recorded; every flag repaired or individually justified; explicit approval; post-approval NDM executed and registered; all files and counters reconciled. No unreviewed finding or missing history. Gate cannot be passed by an AI score. For the first chapter, verify zero prior approved chapters and compare against research examples manually; no reuse of the 75 original examples as prose.
