# Competitive accuracy architecture v1.0
Data: RIFTBOUND/ source registry, official banlists 2026-11-23, seed metadata, private snapshot importer. Real card data are versioned independently of fictional narrative. No live data query determines historical legality. Distinguish gameplay identity vs printing, token vs legal main-deck card, preview vs released, US vs other regions. 
Process: import and reconcile official gallery/errata → freeze rules PDF and tournament PDF + FAQ → build effective card text per date, preserve printed text → legal deck validation → deterministic replay with independent POVs → editorial selection → audit narrative. Rules hub authoritative; community snapshot contains manual corrections and cannot override Riot. Validate exact card identity, zone, cost, power, timing, priority, target legality, action chains, scoring and resulting state. 
Rift Duels integration remains pending inspection; Riot policy restricts digital clones. Use paper match logs or permissible private editorial verification; no public simulator based on Riot IP. 
Data schema: ruleset_id, format_id, region, effective_date, source refs and hashes; printings and canonical identities, errata history, bans; replay_id, ruleset, decklists, public/private state, seed, legal actions, action log, priority, effects, points and outcome. Store game state separated from player information. Plot stakes can select among legitimate match results; no manipulating draw/seed until protagonist wins. G3-global remains incomplete; G3-scene uses scoped rule verification per SCENE_INTEGRITY.md. No external replays required.
